日志分析系统说明文档

本系统用于分析和处理各类日志文件，支持多种日志格式的解析和统计。

系统架构：
1. 日志采集模块 - 负责从各种数据源采集日志
2. 日志解析模块 - 负责解析不同格式的日志
3. 日志存储模块 - 负责将日志存储到数据库
4. 日志查询模块 - 负责提供日志查询接口

支持的日志格式：
- Apache 访问日志
- Nginx 访问日志
- Java 应用日志
- 系统日志

使用方法：
1. 配置日志源
2. 启动采集服务
3. 查询和分析日志

注意事项：
- 请确保日志文件编码为 UTF-8
- 大文件处理时请注意内存使用
- 建议定期清理历史日志
