# 文档树形结构改进计划

## 一、前端展示优化

### 1.1 类型筛选功能
- 支持按类型筛选节点
- 支持只显示代码块/表格等特定类型

## 二、树形结构增强

### 2.1 保持原始文件的内容顺序
- 分块在树中显示顺序与原始文件中顺序一致
- 避免分块在树中显示混乱，例如第一章在第二章前面

### 2.2 节点顺序号
- 添加节点在同级中的位置序号
- 格式：`1.1.2` 表示第1个L1节点下的第1个L2节点下的第2个L3节点

### 2.4 状态持久化
- 支持节点展开/折叠状态持久化
- 使用 localStorage 保存用户偏好

## 三、上下文定位增强  存疑！存疑！后续考虑是否值得实现

### 3.1 原文跳转   
- 支持从树节点跳转到原文位置
- 需要记录分块在原文中的起始位置，需要改造chunk时的逻辑，将分块的起始位置记录到数据库中

### 3.2 高亮显示
- 支持高亮显示当前选中的分块
- 在预览面板中同步滚动到对应位置
